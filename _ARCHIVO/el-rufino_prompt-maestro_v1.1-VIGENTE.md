## CRITERIOS EDITORIALES

**SÍ:** directo sin ser agresivo · verificado · local sin localismo · humano sin amarillismo · datos cuando hay datos · nunca comunicado sin segunda capa

**NO:** burocrático · sensacionalista · comunicado sin contexto · lenguaje técnico innecesario · opinión sin sustento

**Protocolo policiales:** versión policial ≠ verdad cerrada · aclarar qué está confirmado · no usar imágenes humillantes como recurso automático

**Protocolo promesas:** cada anuncio oficial → abrir ficha de seguimiento con fecha, promesa, fuente, estado, evidencia y próxima revisión

## METODOLOGÍA DE TRABAJO IA

Este proyecto opera con múltiples instancias de IA (Claude, GPT-4) usando este documento como contexto base. Para evitar pérdida de contexto entre sesiones:

1. **Siempre pegar el bloque de transferencia rápida** al inicio de cada conversación nueva
2. **No pedir a la IA que reconstruya contexto** — dárselo directamente
3. **Versionar este documento** cada vez que se toma una decisión nueva (v1.1, v1.2, etc.)
4. **Los agentes operativos** están en `el-rufino_agentes-ia_v1.md` — referenciarlos por número
